### 2.3 关键裁决（Lead 冻结，写入 `00_方案与分工.md`）

1. 身份判定与显示分离：新增 `_IdMap`，只在 `.mat` 静态赋值、运行时不改、不走 `MaterialPropertyBlock`（MPB 设纹理**不会**填 `_IdMap_TexelSize`，会让描边宽度归零）。
2. 运行期材质写入一律走 MPB；`Assets/Map/MapMat.mat` 里烘焙的 `_HasSelection=1 / _SelectionBlend=1 / _SelectedId=1008 号色` 必须清零——**开局自带高亮的真凶**。
3. `_SelectedId` / `_HoverId` 必须声明为 `Vector` 而非 `Color`：`Color` 在 Linear 项目下会被 Unity 做 sRGB→Linear 转换，0–1 编码的 ID 会被破坏。
4. shader 新 property 默认值一律 0（与改动前逐像素等价），目标观感值写进 `.mat` → 改一行 `.mat` 即可整体回退。
5. 省名"JSON + `.asset` 双写"：运行时真源是 `Assets/Province/ProvinceDatabase.asset`（`.asset` 用 `\uXXXX` 转义，JSON 用原始中文），只改一边不生效。
6. 文案单点来源：所有玩家可见字符串进 `Assets/UI/UICopy.cs`，程序不得硬编码。

### 4.3 shader 真编译（"地图会不会变紫"的最强证据）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\shader-check.ps1
```

用 Windows SDK 的 `dxc` 按 `SHADER_API_D3D11` 预处理 `Assets/Province/ProvinceSelect.shader` 后分别编译两个入口：`vert vs_6_0` 8720 B、`frag ps_6_0` 10312 B，**双入口 PASS**。它证明的是语法与预处理层面无错（HLSL 变量名冲突、属性与 CBUFFER 不一致、未定义符号都会被它挡下）；平台宏差异导致的运行时失败仍需你实机确认。

## 5.0 需要你在编辑器里目视确认的清单

本轮**没有任何自动化手段能代替实机目视**：Unity 编辑器正被你占用（`Temp/UnityLockfile`），截图脚本 `Assets/Editor/ReefScreenshot.cs` 需要 `-batchmode`，且它只渲染 `Camera.main`，Overlay 的 HUD 根本不进图。请按下面顺序看，括号内是"合格"判据。

1. **开局**：整幅地图入画、四周是纸灰底色而不是天空盒蓝；**不应有任何省份自带黄色高亮**（这是本轮修掉的烘焙脏值）。
2. **点省份**：黄铜色描边 + 半透明纸色填充 + 纸底深字标签 + 详情面板出现。
3. **悬停**：轻高亮随鼠标移动，移开恢复；**鼠标压在文字/标签上仍能点到地图**（原来文字在挡点击）。
4. **`Esc`**：清除选中（高亮、标签、详情面板一起消失）。
5. **渗透模式**：点省份加入/移出名单，**描边不会消失**；提示条显示「已选 N/3」；超过上限时提示条变红加粗约 0.6 秒且不再加入。
6. **相机**：滚轮缩放锚定在鼠标位置、地图不会被拖出屏幕、`R` 复位；**顺带看一眼帧率**——渗透开关会触发 267 万像素的贴图重算，这是唯一未做优化的性能点。
7. **事件弹窗**：文案不再出现 `TestEvent1` / `OptionA` / `revolution` 这类占位或英文 id，选项提示是中文。
8. **情报日志**：标题「情报日志」，未解锁条目带「 · 因果迷雾」。
9. **顶栏**：`卢泰西亚国` + `吕西安·马尔索`；日期/暂停按钮正常。
10. **底栏 5 个入口**：未开放的三处显示「未开放」且灰掉（**没有假进度格**），渗透处可点、机构总览可点。
11. **分辨率**：把 Game 视图拉到 1280×720 与 2560×1440 各看一眼，UI 应等比缩放、底栏不重叠。

> 如果地图整片**洋红/品红**：说明 shader 在你机器上编译失败（我已用 Windows SDK 的 dxc 按 SM6.0 编过 vert+frag，两个入口都过，所以更可能是平台宏差异）。请把 Console 的报错原文发我。
