## 1. 会议纪要（四角色立场与处置）

| 角色 | 核心主张 | 处置 |
|---|---|---|
| 策划 | 本轮目标不是"更好看"，而是**停止让界面撒谎**：清掉假选中、占位文本、假承诺，让地图可读（13 省名 + 全图入画）；精致度排第二批 | 采纳。其"开局占位事件"是本轮 P0，已补进 T7（Lead 原清单确实漏了这条） |
| 美术 | 纸感由"底"扛、不由省色扛；只在**显示路径**做洗淡（拾取走 CPU `GetPixels32`，不动 ID 也安全） | 采纳，wash 预算 0.40（实测两省最小 RGB 距离 34.6） |
| 程序 | 只改材质写入通道不够，必须拆 `_IdMap`；`_IdMap_TexelSize` 不会被 MPB 自动填充 | 采纳，但**改用法**以规避该陷阱：`_IdMap` 只静态写在 `.mat`，永不通过 MPB 设置（见 2.1） |
| 文案 | 玩家侧一律称「省份」；术语与硬编码字符串集中到 `UICopy` | 采纳；「未启用」改为**「未开放」**（以策划 AC 表用词为准，见 2.3） |

被否决 / 修正的主张（每条都写了"因为…"）：

1. ❌ **悬停高亮复用 `_SelectedId`** → 改用独立 `_HoverId`/`_HoverStrength`。因为一个 Vector 属性只能承载一个语义，悬停会不断覆盖选中态，选中反馈随鼠标移开而消失。
2. ❌ **shader 新 property 默认值直接写目标观感值**（美术 6.4 建议 0.40/0.15/0.55/0.35）→ **shader 默认一律为 0**（与今天逐像素等价），目标值由美术写进 `MapMat.mat`。因为要能"改一行 `.mat` 就整体回退"，且 `.mat` 若漏写新 property 时绝不能发生视觉突变。
3. ❌ **用 MPB 设置 `_IdMap`** → 改为 `.mat` 静态赋值。因为 MPB 不填充 `_TexelSize`，会让描边宽度算成 0。
4. ❌ **本轮不做开局自动暂停**（策划 P0-① 的另一半）→ 因为时间流属机制层、超出"视觉表现"范围，且最终由用户验收；本轮先消除占位文案，暂停与否列入"下一轮待定"。
5. ❌ **本轮不动 13 省 ID 配色、不重绘 `map.png`** → 因为 ID 颜色是拾取键，牵动 `map.png` + `ProvinceDatabase.asset` + `ProvinceData.json` 三方一致性（评审报告 P0-1 高风险区）。
6. ❌ **本轮不加 ShadowCaster/DepthOnly pass、不做 9-slice 圆角** → 前者无可见收益（正交俯视、无投影体），后者需程序化生成 Sprite，都不属于最小改动集。
7. ⚠️ **美术备忘的行号需更正**：`_FillTint`/`_OutlineColor`/`_OutlinePixels` 不在 `:35/:49/:55`，实际在 `Assets/Map/MapMat.mat:140/:141/:121`，且 `_FillTint` alpha 是 **0.35（不是 0）**。所以开局"脏高亮"是**填充与描边同时生效**，比备忘描述更严重 —— 以本文件为准。

**必须实现的判据切换**（工程师给出的行级要求，美术落地）：
- `:78/:90/:104/:111-112` 的 ID 采样与 `SameId` 判据，从 `_BaseMap` 改为 `_IdMap`（`sampler_IdMap`）。
- 出口显示色仍只取 `_BaseMap`；`SRGBToLinear` 只在出口做一次。
- **洗淡/压色只作用于出口色，绝不能回灌到 ID 比较路径**，否则拾取与描边一起坏。
- 新增 property 必须同时出现在 `Properties` 块与 CBUFFER（`UnityPerMaterial`），否则 Inspector 可改但 shader 读不到（静默失效）。

**绝不能动**：`_SelectedId` 保持 Vector；描边宽度语义保持源 texel 单位；`map.png.meta` 的 `isReadable: 1` 必须保留（CPU 拾取依赖）；`enableMipMap` 保持 0；纹理 alpha 保持 1。

### 2.5 相机取景（属主：程序；判定值）

- `orthographicSize` 由地图包围盒 + **HUD 安全区**推导：地图必须完整落在"顶栏 70px + 底栏 80px"之间，而不是只按整屏高度。1080p/16:9 参考值 ≈ **7.0**（策划要求 ≥6.6）。
- `maxZoom`（最远）= `fitSize × 1.10`。因为美术实测"描边断续"的真因是缩到最远时地图仅占 432×324 屏幕像素（4.4× 缩小 + 无 mipmap）；`CameraPanController.cs:23` 原 `maxZoom=20` 必须收紧。
- 缩放锚定光标、平移钳制（地图小于视野时锁中心）、静止时不写 transform、`R` 键复位。
- 相机 `clearFlags = SolidColor` + `backgroundColor = UITheme.MapBackdrop`，**用代码在 Awake 设置**（禁令见 2.0）。
