## 62.3 UIPanelChrome 设计（新文件 `Assets/UI/UIPanelChrome.cs`，属程序）
目标：七个面板一句话套用；参数取 P1/P2/P9 定值；构建期一次性建完，Update 零开销。
```csharp
public struct PanelSpec {                 // 默认值即 P1 定稿，调用方只填差异项
    public string title;                  // 空 = 不画标题栏；subtitle 可空
    public Color  bg, border, innerHighlight;  // PaperBg / Divider 1px / 顶部 1px 内高光
    public Color  accent;                 // 左侧 3px 竖条（§3 选中态），a=0 不画
    public bool   shadow;                 // ShadowColor + ShadowOffset(0,−3)
    public string seal;                   // 斜章文字（P10/U-18），空 = 不画
    public int    titleSize;              // FontTitle = 32（P1）
    public float  titleBarH, pad;         // 56 / 20（P1/P2）
}
public sealed class PanelChrome : MonoBehaviour {
    public RectTransform Content { get; } // 已扣标题栏 + pad ← 迁移方唯一要用的东西
    public Text  Title { get; }  public Image Background { get; }  // 底纸 raycastTarget 保持 true（面板照旧挡地图）
    public Image Border { get; } public Image Accent    { get; }   // 四边线 raycastTarget = false
    public void SetAccent(Color c);  public void SetAlert(bool on);  public void SetDisabled(bool on);
}
public static class UIPanelChrome {
    public static RectTransform Create(Transform parent, string name, in PanelSpec spec,
        Vector2 size, Vector2 anchor, Vector2 pivot, Vector2 offset, out PanelChrome chrome);
    // 迁移用增量件：给已存在的手写面板补装饰，不动其既有布局代码
    public static Image AddBorder(RectTransform host, Color color, float width = 1f);
    public static RectTransform AddTitleBar(RectTransform host, string title, int size, float h = 56f);
    public static Image AddDivider(RectTransform host, float y, Color color);
    public static Image AddShadow(RectTransform host, Vector2 offset, Color color);
    public static RectTransform AddSeal(RectTransform host, string text, Vector2 anchor, Vector2 offset, float size = 44f);
    public static Image AddRedactionBar(Transform parent, float width, float height);   // U-16 打码条
}
```
绘制顺序（同一 Canvas 内自下而上）：影子 → 底纸 → 左侧色签 → **内容区** → 四边线 → 标题下分隔线 → 标题/副标题/斜章；内容区在线之下，保证 1px 线永远压住文字边。

## 62.4 程序化装饰：路径与代价（P8 / P9）
- 描边 / 分隔线 / 色签 / 打码条：**无 Sprite 的 Image**（UGUI 画纯色四边形），零贴图零内存可合批，一板 4 根线 + 1 条分隔线；不用 1×1 贴图、不改 Shader。
- 圆角 + 1px 线：按 **P9 配方**做唯一生成器——128×128 RGBA32、圆角 24px、描边 4px、内高光 4px、`Sprite.Create(..., pixelsPerUnit:400f, 0, SpriteMeshType.FullRect, border:32)` → 屏上 6px 圆角 / 1px 描边（4 倍过采样防糊）。**静态缓存 3 个变体**（普通/选中/禁用）≈ 192KB + 3 个 Sprite；P1「圆角半径差 ≤1px」由此天然成立（U-02）。生成失败回退直角版（仍画四边线），签名不变。
- 投影：第二层同款 9-slice Image 染 `ShadowColor`(a=0.28) + `ShadowOffset`(0,−3) → +1 DrawCall、不复制文字顶点；不建议给面板挂 UGUI `Shadow`（无法圆角，且和"影子撑到纸外"绑死）。
- 斜章 / 朱砂戳记（P10、§5 备选）：`Text`(1~2 字) + `Outline`、`SealRed`、`localRotation = Euler(0,0,−6°)`、`raycastTarget = false`；盖章入场复用 `UIAnim.Stamp`。
- 卡片墙 + 贯穿线索（§5 主提案）：贯穿线 = 1px 无 Sprite `Image` + 8px 圆点（同 9-slice 圆形变体或 16×16 缓存）；静态卡片无需每帧逻辑，新链揭示只对新增卡跑一次 `Stamp`。
- 五态通路（§3 / P6）：建议同批新增 `Assets/UI/UIButtonState.cs`（`PointerEnter/Exit/Down/Up` → 描边色 + 上浮 2px/0.12s + 按下 0.98/0.06s），并让 `UIFactory.CreateButton`（`UIFactory.cs:101-102`，`:111` 现为 `Transition.None`）默认挂上；**这是 §3 能否达成的关键件，光做 chrome 不够**。
- 成本：9 画布 7 面板，每块 +2~4 DrawCall（四边线 +2、影子 +1、斜章 +1），总量 < +20，同 Canvas 可合批；**每帧分配 0**（装饰全在构建期，运行期只改 `CanvasGroup.alpha` / `anchoredPosition`）。
