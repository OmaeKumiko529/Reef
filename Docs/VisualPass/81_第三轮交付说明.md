# 81.0 第三轮交付说明（纸印素材）

> 一句话：这一轮把 UI 从「纯色矩形拼出来的原型」推到「有纸、有墨、有章」的样子 —— 纸墨素材由代码离线生成，**三枚朱砂章 + 按钮基底 + 边框样式由 Affinity 原生绘制**（矢量字形/框线 + 后处理），全部接在原有 UGUI 上，**素材缺失会自动退回上一轮外观**。

## 81.1 你要做的验收（6 步，每步都能"看"出来）

> 前置：Unity 已开着 `Assets/Scenes/SampleScene.unity`。切回编辑器窗口让它导入新资源（首次导入 14 张图，约 1 秒）。**看 Console 有没有 `[Reef] UIArt 素材缺失…`**：有＝素材没被识别成 Sprite，把该警告发我。

| # | 操作 | 合格判据 |
| --- | --- | --- |
| 1 | 直接 Play，看开局 | 面板纸底**四周有一圈做旧的深边**（不是均匀色块）；双线框是**深浅不匀的墨线**；标题栏是一条压暗的纸板，下沿 2px 墨线，左端仍有朱砂竖块 |
| 2 | 看**地图本体**（不是面板） | 地图上多了一层**很淡的印刷网点 + 颗粒**，屏幕四角**略暗**；UI 面板上**没有**这层网点（它只压在地图上） |
| 3 | 鼠标扫过底栏 5 个入口与任意按钮 | 五态仍分明（普通/悬停/按下/选中/未开放）；按钮表面是**矢量画的压印板**（上缘一道压痕、下缘与右缘一道纸厚暗边、圆角） |
| 4 | 点一个省份 → 看详情面板；再点开情报日志 | 详情面板纸底是①的样子；情报日志的**锁定卡**里是**两端收笔、上缘带干墨**的打码条，贯穿线上的节点是**软边墨点**；「未开放」是**真章面**（缺角、断笔、−8°），不再是细方框。**这一枚印章本轮换成 Affinity 矢量字形版**（`Tools\.uiart\stamp-inkpass.png` 有前后对照）：字口清楚、笔画完整，重墨 7% / 半透 34%，比旧程序化版的字形可读性高一档 |
| 5 | 点一下地图、点一下按钮、拉一下地图 | **点击全部照常生效**（叠层网点/颗粒/暗角不吃点击）—— 这一条最重要，若点不动请立刻截图给我 |
| 6 | （复核新增）把 Game 视图分辨率改成 **1280×720 与 2560×1440** 各看一眼 | 地图上的印刷网点**没有出现摩尔纹/水波纹**（网点是 Point 过滤的 64px 平铺，缩放比不是整数时理论上可能起纹）。若起纹：把 `Assets/UI/UIArt.cs` 里叠层那张 `RawImage` 的 `filterMode` 改成 `Bilinear`，或把 tile 尺寸改成 128（改 `gen-uiart.py` 后重跑一次生成器） |

**想要"实机证据"**：Play 后点菜单 **`Reef/截图当前游戏画面`**（`Assets/Editor/ReefScreenshot.cs`），会把 MainCamera 渲成 PNG 写到 **`Logs/ui_capture.png`**（1920×1080，`Logs/` 已被 .gitignore 忽略）；也可以用 **`Reef/预览：进入Play并截图`**（`Assets/Editor/EditorScenePreview.cs`）自动进 Play 并截图。把那张图发我，我就能拿实机画面继续调。

**对照参考图**（离线渲染的近似效果，不是 Unity 截图）：[preview-sheet.png](Tools/.uiart/preview-sheet.png)（面板骨架 / 按钮五态 / 事件选项行 / 日志卡片墙 / 单件放大）、[contact-sheet.png](Tools/.uiart/contact-sheet.png)（14 件素材原图）。

## 81.3 已知风险与回退

1. **风险：Unity 未把素材识别为 Sprite** → 现象＝Console 出现一次 `[Reef] UIArt 素材缺失…`，界面仍是上一轮外观。处置：删掉 `Assets/Resources/UIArt/*.png.meta` 让 Unity 重新导入（生成脚本会重新写 meta）。
2. **风险：观感过强/过弱**（做旧边太脏、网点太抢）→ 只改一个数：`Assets/UI/UIArt.cs` 的 `BuildScreenOverlays` 里网点/颗粒/暗角 alpha（现为 1 / 1 / 0.85），或 `Tools/gen-uiart.py` 里两张 tile 的 alpha 系数（改完重跑一次生成器）。
3. **一步回退**：把 `Assets/Resources/UIArt/` 整个目录移出 `Resources`（或删掉）→ 全部走降级路径，界面回到上一轮外观，**不用改一行代码**。
4. **彻底回退**：`git checkout -- Assets/UI/UIArt.cs Assets/UI/UIPanelChrome.cs Assets/UI/UIFactory.cs Assets/Intelligence/CausalChainManager.cs Assets/Province/ProvincePicker.cs` 并删除 `Assets/Resources/UIArt/`（此时 `UIArt.cs` 已删，其余文件不该保留引用）。
5. **未做 / 已改口（如实登记）**：① **实机验证**——本会话禁止再启 Unity（你开着编辑器），所有效果图都是离线近似渲染；② ~~Affinity 精修~~ → **本轮已做**（第三轮补做：用户追问后实测 Affinity 已在运行，用自写 MCP-over-SSE 客户端画了三枚印章矢量图 + 印泥后处理，见 `80_` §80.10；随后按用户 `m03193` 又画了**按钮基底 + 标题纸板 + 双线框**，见 §80.11）；纸底/网点/颗粒/暗角仍是程序化生成——它们是随机场，矢量工具做出来反而更平（对照见 `Tools\.uiart\affinity-compare.png`）；③ 字体仍是系统字（铅字感标题字形留到下一轮）；④ 纸纹是屏幕叠层，不是跟随地图的真实纸纤维；⑤ 盖章动画（素材章目前静态显示）。
6. **已修（独立复核 🔴 + 🟠1 + 复核 V2 的三条护栏）**：① 两张平铺贴图的 Wrap Mode 原本被生成器**硬编码成 Clamp**，导致网点/颗粒只在屏幕最左/最下 64px 露出 —— 已把 `Tools\gen-uiart.py` 改成按 `WRAP_REPEAT = {"grain_tile", "halftone_tile"}` 写 `wrapU/wrapV: 0` 并重生成 14 份 meta（含脚本内 meta/像素两道自检）；② 14 份 meta 的 `spriteMeshType` 由 `1`(Tight) 改为 `0`(Full Rect)，9-slice 才可靠；③ 复核第二轮（`65_§65.10`）结论**可交付、0 条新 🔴**，但用 13 次突变实测指出门禁三条"假绿"：导入字段（compression/sRGB/maxSize）未入闸、border 只做"meta == 生成器"而不钉期望值、H3 只数 `raycastTarget = false` 不查有没有被打开 —— 已分别扩到 8 项 needle、在门禁里**硬编码期望 border 表**（meta 与生成器各自对表）、要求 `raycastTarget = true` 恒为 0，并把 H1a/H1b 正则改为认大写名；④ 新增 `Tools\uipolish-mutation-test.ps1`（纯 ASCII、`try/finally` 恢复 + SHA256 核对）：注入 3 类真实故障 A/B/C → 实测各触发 1 条 FAIL（H2/H2/H3），恢复后回到 45/0 且逐字节还原。修完复跑三门禁全绿（45/0、34/0、0 error/11 warning），`SampleScene.unity` 未动。
