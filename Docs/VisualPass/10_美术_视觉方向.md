# 3.0 行号更正：开局脏高亮的真实规模
`Assets/Map/MapMat.mat` 改动前实测：`_HasSelection: 1`（`:118`）、`_OutlinePixels: 2.5`（`:121`）、`_SelectionBlend: 1`（`:126`）、`_FillTint` a=**0.35**（`:140`）、`_OutlineColor` a=1（`:141`）、`_SelectedId = 1008`（`:142`）。

# 4.0 洗淡/压色：数值与观感
- 算法在 sRGB 空间：`c' = c*(1-wash) + lum(c)*wash`，再乘纸色乘子 `(1.0, 0.961, 0.866)` 按 `_PaperTint` 插值，最后由 `SRGBToLinear` 一次性转 linear 出口（`ProvinceSelect.shader:103-111`）。
- 落盘值 `_PaperWash 0.40`（`MapMat.mat:128`）、`_PaperTint 0.15`（`:127`）：省色降饱和并整体压暖。预算实测：`wash ≤ 0.50` 时任意两省的最小 RGB 距离仍 ≥ 29.5，取 0.40 时为 34.6，远大于 `SameId` 容差 ≈10/255（`shader:116`）→ **不会误判**。
- 白色不动是数学事实，不是参数没调够：`lum(#FFFFFF) = 1.0`，洗淡对它无操作；纸色乘子只把纯白压到 `#FFFDF9`。要把白场压下去，只能靠 `_Vignette` 或相机背景色。

# 5.0 暗角用 UV 空间而非 Volume
`_Vignette` 在 UV 空间计算（`ProvinceSelect.shader:188-190`）→ 暗角跟着**地图**走，缩放时像"纸的边角失光"；URP Volume 的 Vignette 是全屏的，相机拉远后只剩屏幕四角发暗、地图本身反而变亮。地图侧因此弃用 Volume 暗角。

# 6.0 身份图分离（修 P2-3）
- `_IdMap` 只在 `.mat` 里静态赋值（`MapMat.mat:65-68`，沿用 map.png guid `a18e1f9b22de462418ed12e3a7cd5063`），运行时不改、**不走 MPB** → 渗透期 `_BaseMap` 被程序换成 penMap 时（`Assets/Agency/PenetrationManager.cs:234`，换图逻辑 `:243-259` 按契约走 MPB），身份判据仍读原图，描边不再整体消失。✅
- 顺带的收益：`_IdMap_TexelSize` 一定有值，描边宽度不再受"MPB 设纹理不填 TexelSize"影响。
- 显示路径与身份路径彻底分开：`_BaseMap` 只出显示色（`:169`），`_IdMap` 只做身份判据（`:162-166`），`PaperLook` 的返回值绝不回流比较路径。

# 7.0 采样硬化（`map.png.meta`）
- `filterMode 1 → 0`（Point，`:37`）+ `textureCompression 1 → 0`（None，`:75`、`:88`）：ID 采样零压缩误差、省界 1 texel 内不再混出中间色。
- 这同时缓解"描边点状断续"的主因：`CameraPanController.cs:23 maxZoom = 20f` 允许缩到地图只占约 432×324 屏幕像素（对 1890×1417 贴图是 4.4× 缩小），双线性下每个输出像素吞约 19 个源 texel，边界混合色对两侧都 `SameId = false` → 描边整段消失；Point 采样不再产生这类混合色。
- `isReadable: 1`（`:24`）必须保留：CPU 端拾取靠 `GetPixels32`（`Assets/Province/ProvincePicker.cs:137`）。
