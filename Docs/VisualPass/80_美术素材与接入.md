# 80.0 第三轮：纸印 UI 素材与接入

本节记录第三轮「UI 还是太原型化」的处置：**离線生成一套可染色的纸印素材，并接进现有 UGUI**。

## 80.1 目标与结论

1. **目标**：在不引入 Affinity / 不引第三方素材 / 不改场景文件的前提下，把「面板只有一层纯色矩形」这件事从根上解决 —— 纸要有纸纹与做旧边，框要有墨线的干湿，按钮要有压印，印章要用真章面。
2. **结论**：已产出 **14 件 PNG（合计 ≈ 135 KB）** 落在 `Assets/Resources/UIArt/`，由 `Assets/UI/UIArt.cs` 在运行期装载，接在 9 类 UI 上；**素材缺失时整套界面回退到第二轮外观**（不报错、不空屏）。
3. **验证**：静态编译门禁 `0 error / 11 warning`（与基线逐条一致）；`Tools\uipolish-check.ps1` **45 passed / 0 failed**（41 条原有 + 独立复核后补的 4 条素材断言 H1a/H1b/H2/H3）；`Tools\visualpass-check.ps1` **34 passed / 0 failed**。❗**仍未实机验证**（用户 Unity 正在运行，本会话禁止再启一个进程），实机观感与 1px 细线在 1440p/4K 下的表现为已知取证缺口。独立复核见 `65_素材接入复核.md`，本轮对其 🔴/🟠 的处置见 §80.9。

## 80.2 方法与工具链

1. **生成**：`Tools\gen-uiart.py`（纯 Python + numpy + Pillow，**确定性随机种子**，可重复生成；`python Tools\gen-uiart.py` 一条命令重建 11 件程序化素材与全部 `.meta`）。三枚印章由 Affinity 产出，脚本里只在清单中登记规格、**不再用 PIL 重画**（`AFFINITY_ASSETS`；需要旧版走 `--force-stamps`）。
2. **预览**：`Tools\uiart-preview.py` → `Tools\.uiart\contact-sheet.png`（素材对照）+ `Tools\.uiart\preview-sheet.png`（**接入后的近似效果图**：面板骨架 / 按钮五态 / 事件选项行 / 日志卡片墙 / 单件放大）。⚠ 预览是**离线渲染的近似**，不是 Unity 截图，字体与 1px 线的真实表现以编辑器为准。
3. **Affinity 原生绘制（三枚朱砂章，第三轮补做）**：`m01681` 提到的 affinity MCP 当时没进本会话，后来用户点名追问（`m02687`）→ 重测发现 Affinity 已启动、`localhost:6767` 在监听，于是**手写了一个 MCP-over-SSE 客户端**（`Tools\.uiart\affinity-mcp.py`）直接驱动它：在 Affinity 里建文档 → 矢量矩形（印刷框线）+ 艺术文字（项目 Noto Serif SC 的字形，`StoryBuilder` + `ArtTextNodeDefinition`）→ 导出 PNG → 关文档。源脚本 `Tools\.uiart\art-batch.js`（9 件一次画完，`.afdesign` 源文件存桌面 `reef-uiart\src\`），再用 `Tools\uiart-inkpass.py` 给干净矢量过一遍**朱砂印泥后处理**（颗粒 / 干擦条纹 / 边缘啃噬 / 洇墨 / 二次落印），写回 `Assets\Resources\UIArt\`。详见 §80.10。

**素材设计规则（沿用即不要破坏）**

1. **中性白 + alpha**：素材只带明度与 alpha，**颜色一律由 `UITheme` token 通过 `Graphic.color` 给**。这样五态换色、`ChromeState.Disabled` 灰化、Modal 反白全部照旧生效；**不要**把颜色烘进贴图。
2. **9-slice 边即像素即 UI 单位**：`spritePixelsToUnits=100` + Canvas `referencePixelsPerUnit=100`，因此 `spriteBorder` 的像素数＝参考分辨率（1920×1080）下的 UI 单位数。改边值必须同步改生成脚本。
3. **只切必要的边**：纸/线环/按钮四边都切；标题栏、档号、打码条只切左右（这样 16px 高的打码条也能用）。
4. **导入设置**：`textureType: 8`（Sprite 2D/UI）、`sRGBTexture: 1`、`enableMipMap: 0`、`textureCompression: 0`、`maxTextureSize: 256`、`spriteMeshType: 0`（Full Rect，9-slice 必须）；两张平铺贴图 `wrapU/wrapV: 0`（Repeat），其余 `1`（Clamp）。这些字段由 `Tools\gen-uiart.py` 写入，脚本末尾自带 **meta self-check**（对不上就直接返回 exit 2，不会把坏 meta 留在磁盘上）。
5. **零运行期生成**：UIArt **不** `new Texture2D`、不 `Sprite.Create`（与契约 §1.0 禁令一致；`uipolish-check` C1 守着这条）。

## 80.5 容错与降级（三条硬要求）

1. **素材全缺** → 所有 `Apply*` 静默跳过、`BuildScreenOverlays` 返回 null → 界面＝第二轮外观，不抛异常、不空屏；`UIArt.Get` 只记**一次** `Debug.LogWarning` 便于定位。
2. **点击不能被打断**（第二轮出过「点不了任何东西」的事故）→ 叠层画布的子物体全部 `raycastTarget=false`，`CanvasGroup.blocksRaycasts=false`；`uipolish-check` 的 C1/N4/N5 分别守住「不新建贴图」「`AddComponent<Graphic 子类>` 前必须判空」「印章句柄独立 GameObject」。
3. **单件缺失** → 只有那一处回退纯色（例如只有 `binding_dot` 没导入，则线索节点仍是纯色方块）。

## 80.6 用户可见变化

1. 九块面板的纸底出现**做旧边与纸纹**，不再是均色矩形（截图里最明显的一处）。
2. 双线框变成**干湿不匀的墨线**（外框略毛、内线挺），细线仍是 1px。
3. 标题栏是一条压暗的**纸板**，下沿 2px 墨线，左端朱砂竖块照旧。
4. 按钮有**压印凹陷**（上暗下亮），五态色不变。
5. 「未开放」斜章由程序化方框换成**真章面**（缺角、断笔、−8°），底栏入口与面板通用。
6. 情报日志的锁定卡打码条**两端收笔、上缘干墨**；贯穿线上的节点是软边墨点。
7. **地图之上多了一层纸感**：印刷网点（64px 网格）+ 颗粒 + 屏幕暗角，让 14 色高饱和地图与纸墨 UI 不再像两套东西。
8. 档号角标（如「档号 渗-01」）有了纸片底与内缩留白。

**踩坑（务必记住）**

- **Affinity 的脚本沙箱只允许导出到 `Application.userDesktopPath`**（`Application.userDesktopPath` 下的子目录可以，任意绝对路径报 `PERMISSION_DENIED`）。所以 PNG 先落桌面，再由 Python 脚本搬运。
- **`File → Scripting` 的权限**：`Document.export / saveAs` 走的是应用内权限，MCP 的 `execute_script` 能直接跑；不需要在 UI 上点任何东西。
- **笔刷参数不要给 `FillDescriptor.createNone()`**：它会被当成"用当前填充" → 整个形状被实心涂满（曾画出一整块红）。**只描边**就传 `brushFill = null`。
- **`LineStyle` 不能直接当 `lineStyle` 实参**，要 `LineStyleDescriptor`（`createDefault(weight)` / `createDefaultWithWeight(w)`）。
- 画完要 `doc.saveAs(...)` 再 `doc.close()`，否则会留一堆未保存文档在用户面前。

**为什么纸底/网点/颗粒没有一起换成 Affinity**：这些素材的本质是**随机场**（纤维、做旧边、网点、暗角），Affinity 是矢量工具、没有程序化噪声；离线对照（`Tools\.uiart\affinity-compare.png`）里 Affinity 版纸板是纯色白块 —— 直接染色后比程序化版**更平**。故按"谁强用谁"分工，并把这条写进契约 §17.6。
