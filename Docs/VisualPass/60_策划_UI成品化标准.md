# 2.0 「成品化」的 10 条可判定判据
- P1 统一面板骨架：每个可见面板 = 纸卡（圆角 6±1px / 1px 墨线描边 `UITheme.Divider` / 1px 顶部内高光）+ 标题栏（高 56±2px、字号 `UITheme.FontTitle`=32、左内边距 20）+ 标题下 1px 分隔线。判定：同屏任取两面板，圆角半径差 ≤1px、描边同色、标题栏高差 ≤4px。
- P2 间距只取梯度：内边距与元素间距只能取 `Assets/UI/UITheme.cs:24-26` 的 4/8/12/16/20/30/40。现状违反：底栏 `Assets/Agency/AgencyNavUI.cs:124`=8 ✅、日志 `Assets/Intelligence/CausalChainManager.cs:152`=18 ❌、`:208`=14 ❌、机构与事件卡 `Assets/Agency/AgencyPanelUI.cs:91`、`Assets/Event/EventManager.cs:274`=30/24 ❌、tooltip `Assets/Event/EventManager.cs:320`=12/8 ✅、详情面板手写 20/20/100/80（`Assets/Province/BlockDetailPanel.cs:50-51,59-60`）❌。
- P3 宽度收敛为 3 档：窄 380 / 中 560 / 宽 820，另加两个特例（顶栏自适应、日期牌 300）。现状 8 种：300/380/420/560/620/700/820/1000（`Tools\.recon\magic-numbers.txt:19,36,41,47,62,95,115,125`，另有 360 的 tooltip `:98`）。
- P4 文字不溢出：关键文本（国名串、日期、省名、按钮标签）在参考分辨率下必须单行完整显示。判定 = 目视无换行/裁切；程序侧可断言 `Text.preferredHeight ≤ rect.height`（现状违反见 L-05）。
- P5 层序显式且唯一：每个 `Canvas` 的 `sortingOrder` 必须来自 `Assets/UI/UISorting.cs`，全项目不得再有默认 `0` 与字面量（现状 3 处 0 + 1 处 100，见 §7）。
- P6 五态齐备：所有按钮由同一条状态通路驱动，普通/悬停/按下/选中/禁用可区分（见 §3）。
- P7 点击目标 ≥44×44 参考像素，且命中矩形与视觉边界一致（±2px）。
- P8 无裸色块：任何可见 `Image`（面板/按钮/提示条/遮罩）至少具备"描边"或"投影"之一，否则视为未修饰。
- P9 零新增美术资源：装饰（纸卡/投影/打码条/斜章）必须由唯一程序化生成器产出；禁止新增 `.png`/`.mat`。配方（供程序参考）：生成 128×128 RGBA32，圆角半径 24px、描边 4px、内高光 4px，`Sprite.Create(tex, rect, pivot, pixelsPerUnit: 400f, 0, SpriteMeshType.FullRect, border: 32)` → 屏上得 6px 圆角 / 8px 边框区 / 1px 描边（4 倍过采样保证细线不糊）。
- P10 形态即承诺：未开放/未实装必须用形态表达（灰显 + 角标 + 斜章），同一入口只对应一个面板（现状 `Assets/Agency/AgencyNavUI.cs:186-227` 死面板违反后半条）。

# 3.0 组件五态规范（按钮/入口/选项通用）
- 判定方法：鼠标移上去（悬停）、按住不放（按下）、点击后（选中）、看未开放入口（禁用）各一次。
- 普通：底 `UITheme.PaperTop`（`Assets/UI/UITheme.cs:7`），描边 1px `Divider`（`:13`），字 `InkPrimary`（`:8`），无位移。
- 悬停：底 `Lerp(PaperTop, white, 0.35)`，描边 1px `AccentGold`（`:12`），整体上浮 2px（0.12s，`EaseOutCubic` `:60-64`），**不改变尺寸与布局**。
- 按下：底 `Lerp(PaperTop, InkSecondary, 0.20)`，描边 `InkSecondary`，回落至 0 并缩到 0.98（0.06s）。
- 选中：底 `PaperTop`，描边 1px `SealRed`（`:11`），左侧 3px `SealRed` 竖条，字加粗；**不改字号**（避免整行重排）。
- 禁用：底 `PaperBg`，描边 `Divider` @50%，字 `InkMuted`（`:10`），右上角「未开放」角标 + 斜章，`interactable = false`；禁止整块半透明（会看不清字）。
- 现状差距三条：`Assets/UI/UIFactory.cs:111` 所有工厂按钮 `transition = None`（零态反馈）；底栏只有按下缩放（`Assets/Agency/AgencyNavUI.cs:268-278`）；事件选项只有 tooltip、无底色变化（`Assets/Event/EventManager.cs:373-399`）。
