# 暗礁更新日志格式

生成更新日志时，遵循以下格式（纯文本，不使用 Markdown 标记）。

## 格式模板

```
<git前8位哈希>-<提交日期> 更新日志
贡献者：<贡献者名>

变更概览
<一段话概述本次提交的核心变化>

云文档变化
<数字代号> <章节名>：<大概变化说明>
...
```

## 规则

1. **标题**：`<git 前 8 位哈希>-<YYYY-MM-DD> 更新日志`。日期取提交时间（北京时间 UTC+8）。
2. **贡献者**：`贡献者：<作者名>`，取 git 提交的作者。
3. **纯文本**：不要用 Markdown 格式（不加 `#`、`-` 列表、表格等）。
4. **不写「项目代码变化」**：跳过代码层面的文件级变化。
5. **「变更概览」**：一段话概括本次提交围绕的核心系统与主要动作，不展开细节。
6. **「云文档变化」**：逐条列出，小节名用「数字代号 + 章节名」表示；每条只写大概变化，不写完整改动内容。

## 示例

```
a29882a3-2026-08-30 更新日志
贡献者：黄前不长酒梅子

变更概览
本次提交（a29882a3，重构并更新因果链内容）核心围绕「因果链」系统：数据结构由「多段式」重构为「扁平式」，新增「情报日志」界面，事件系统新增多种效果类型，新增事件「劳工罢工」与因果链「人民之春」，并同步更新总纲文档。

云文档变化
1.0 总纲：新增「阅读与修改前注意事项」提示块
2.2.2.1.1.2 政治思潮：开局占比字段改为已读取并归一化
2.2.3.2.1 因果链：废弃五段式说明，新增设计思路
2.2.4.1.1 技术栈：事件示例新增 reveal_causal_chain 效果
```
